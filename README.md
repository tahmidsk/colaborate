# Colaborate - Bioinformatics Study Repository

This is a demo repository for collaborative learning and study purposes, focusing on bioinformatics workflows.

## Contents

### Whole Genome Sequencing (WGS) Pipeline Guide

A comprehensive step-by-step tutorial for bacterial whole genome sequencing analysis on Linux.

📄 **[WGS Pipeline Guide](WGS_Pipeline_Guide.md)**

The guide covers:
- Environment setup and tool installation (FastQC, FastP, SPades, QUAST, Prokka, etc.)
- Quality control and read trimming
- De novo genome assembly
- Genome annotation
- Taxonomic classification (Kraken2)
- MLST and serotyping
- SNP/Indel detection (Snippy)
- Antibiotic resistance gene identification (ResFinder, CARD)
- Virulence factor analysis (VFDB)
- Pangenome analysis (Roary)
- Phylogenetic analysis (Parsnp)
- Data visualization (iTOL)

## Getting Started

1. Clone this repository
2. Follow the instructions in the [WGS Pipeline Guide](WGS_Pipeline_Guide.md)
3. Ensure you have a Linux system with at least 16 GB RAM and 100 GB disk space
