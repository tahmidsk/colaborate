================================================================================
                    CHIKV Genome Collection - Quick Start
================================================================================

INSTALLATION:
------------
pip install -r requirements.txt

BASIC USAGE:
-----------
./collect_genomes.sh

This will:
  • Search NCBI for up to 200 CHIKV genome sequences
  • Select 20 sequences from each continent (Asia, Africa, America, Europe)
  • Create: all_chikv_genomes.fasta (multi-FASTA file)
  • Create: all_chikv_genomes_summary.txt (detailed report)

CUSTOM USAGE:
------------
./collect_genomes.sh --max-sequences 300 \
                     --sequences-per-region 25 \
                     --output my_genomes.fasta \
                     --email your.email@example.com

TRY WITHOUT INTERNET:
--------------------
python3 example_workflow.py
(Creates example files for learning)

HEADER FORMAT:
-------------
>CHIKV_Strain_Country_Year_Accession
Example: >CHIKV_Ross_India_2006_KJ451624

MERGE WITH YOUR GENOME:
----------------------
# After collection, add your assembled genome:
cat your_assembled_genome.fasta >> all_chikv_genomes.fasta

# Make sure your genome header follows the format:
>CHIKV_YourStrain_YourCountry_2024_YourAccession

NEXT STEPS:
----------
1. Multiple Sequence Alignment:
   mafft --auto all_chikv_genomes.fasta > aligned.fasta

2. Build Phylogenetic Tree:
   iqtree -s aligned.fasta -m TEST -bb 1000

3. Visualize Tree:
   Use FigTree, iTOL, or ggtree

MORE HELP:
---------
./collect_genomes.sh --help
python3 collect_chikv_genomes.py --help
cat CHIKV_GENOME_COLLECTION.md
